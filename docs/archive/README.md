# Archive Index

This directory contains historical planning notes, freeze records, and archived verification material that are not part of the active runtime or submission surface.

## Contents

- `legacy/`: older phase plans, freeze notes, and refactoring reports kept for traceability
- root archive notes: intermediate archived phase documents retained as historical context

## Test Traceability

Historical test-traceability notes were consolidated here from `tests/archive/` so the active `tests/` tree contains only executable test assets.

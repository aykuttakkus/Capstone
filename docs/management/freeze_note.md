# Freeze Note

Calma is in delivery-focused freeze mode.

## Freeze Rules

- do not add new features unless they remove a submission blocker
- prefer validation, bug fixes, and documentation clarity over expansion
- keep the project local-first and deterministic
- do not widen scope into hosted deployment or paid services

## Acceptable Final Changes

- bug fixes that restore documented behavior
- documentation corrections
- test and CI fixes that align verification with actual runtime behavior
- packaging and Docker improvements that reduce submission risk

## Not Acceptable During Freeze

- major UX redesigns
- new product surfaces
- infrastructure migrations
- changes that require re-scoping the demo story
